HDF5 to NPZ conversion – Overview

Purpose

Take an already‑converted HDF5 file, run convert_hdf_to_dsr.py to produce a DSR .npz file, validate it against a ground‑truth NPZ artefact, and publish an HTML validation report together with small link pages.

Required environment variables

  • VBT_JOB_LOGS – directory for log file.
  • CI_PROJECT_DIR – repository root.
  • OUTPUT_NPZ_PATH – absolute path where the resulting .npz must be stored.
  • INPUT_HDF5_PATH – destination for the original HDF5 that will be attached to the CI job.

Command‑line interface

  • --input-dir <Path> (default: input) – folder that contains the attachments/converted.hdf5 file (the file is placed there by the previous step).
  • --output-dir <Path> (default: output) – where the validation HTML report and link files are written.

High‑level workflow

  1. Initialise logging.
  2. Resolve CI_PROJECT_DIR → ci_root.
  3. Move ci_root/attachments/converted.hdf5 into the location expected by the converter: 
    {input‑dir}/attachments/converted.hdf5
    (uses Path.replace with fallback to shutil.move).
  4. Locate the converter script converters/convert_hdf_to_dsr.py.
  5. Create a temporary directory; expected NPZ output: 
    …/output_dsr.npz
  6. Run the converter: 
    python convert_hdf_to_dsr.py --input_file <input‑dir>/attachments/converted.hdf5 --output_file <npz> --bin_size 0.1
  7. Copy the produced NPZ to OUTPUT_NPZ_PATH.
  8. Validate the NPZ against ground‑truth:
    • Validator script: tests/integration/vbt_amu_protocol_pipeline/utils/validate_and_report.py
    • Ground‑truth file: tests/test_data/ground_truth/test_convert_output.npz
    The validator writes its own HTML report to {output‑dir}/test_result_report.html.
  9. Move the original HDF5 file to the location required by the CI job: 
    INPUT_HDF5_PATH
  10. Generate a small link page (input_hdf5_link.html) that points to the attached HDF5.

Produced artefacts (in --output-dir)

  • test_result_report.html – validation summary (green check / red cross).
  • input_hdf5_link.html – download link for the HDF5 that was fed into the DSR conversion.
