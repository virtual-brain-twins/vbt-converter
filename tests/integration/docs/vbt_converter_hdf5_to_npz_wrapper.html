VBT Converter HDF5‑to‑NPZ Wrapper – Overview

Purpose

The wrapper orchestrates the rate_voltage_exporter.py utility which converts a Master HDF5 file (produced by the VBT simulation pipeline) into a compressed .npz archive containing per‑population firing‑rate and membrane‑voltage traces. The wrapper follows the same convention as the other VBT conversion jobs: it moves the attached HDF5 into the expected layout, runs the exporter, stores the resulting .npz at a location defined by the CI job, and produces a tiny HTML link page for the original HDF5.

Required environment variables

  • VBT_JOB_LOGS – directory where the wrapper should write its log file (vbt_converter_hdf5_to_npz_wrapper.log).
  • CI_PROJECT_DIR – absolute path to the repository root (the wrapper uses it to locate the attached HDF5 and the exporter script).
  • OUTPUT_NPZ_PATH – full path where the final .npz must be copied so that the CI job can publish it as an artefact.
  • INPUT_HDF5_PATH – destination path for the original Master HDF5 file that will be attached to the CI job for later inspection.

Command‑line interface

  • --input-dir <Path> (default: input) – folder that must contain the file attachments/master.h5 (the file is placed there by the previous CI step).
  • --output-dir <Path> (default: output) – directory where the wrapper writes the small HTML link page.
  • --num-time-bins <int> (default: 10000) – passed straight through to rate_voltage_exporter.py (argument -b/--num-time-bins).
  • --smoothing-window <int> (default: 10) – passed to the exporter (-w/--smoothing-window).
  • --output-name <str> (default: rates_voltages.npz) – name of the .npz file produced by the exporter (-o/--output-name).

High‑level workflow

  1. Initialise a standard logging configuration writing to ${VBT_JOB_LOGS}/vbt_converter_hdf5_to_npz_wrapper.log.
  2. Resolve CI_PROJECT_DIR → ci_root.
  3. Move the attached Master HDF5 
    ${ci_root}/attachments/master.h5
    into the location expected by the exporter: 
    {input‑dir}/attachments/master.h5
    (first try Path.replace, fall back to shutil.move).
  4. Discover the exporter script: 
    ${ci_root}/converters/rate_voltage_exporter.py
  5. Create a temporary working directory; the exporter will write the .npz file there as 
    {tmp_dir}/{output‑name}
    .
  6. Invoke the exporter with the arguments supplied to the wrapper: 
    python rate_voltage_exporter.py \
  --master-file {input‑dir}/attachments/master.h5 \
  --out-dir {tmp_dir} \
  -b {num_time_bins} -w {smoothing_window} -o {output_name}
    (the script internally builds an argparse.ArgumentParser and calls RateVoltageExporter.run()).
  7. Copy the produced .npz archive to the path defined by ${OUTPUT_NPZ_PATH} so that the CI job can publish it.
  8. Move the original Master HDF5 to the location required by the CI job: 
    ${INPUT_HDF5_PATH}
  9. Generate a tiny HTML link page (input_hdf5_link.html) that provides a download link for the HDF5 file. The file is written into {output‑dir} so that it can be attached to the CI job as an artefact.

Produced artefacts (in --output-dir)

  • input_hdf5_link.html – simple HTML page with a hyperlink to the Master HDF5 that was converted. Enables downstream jobs or reviewers to fetch the raw data.

Reference – Exporter CLI


# rate_voltage_exporter.py (excerpt)

parser = argparse.ArgumentParser()
RateVoltageExporter.configure_parser(parser)
parser.add_argument(
    "--master-file",
    type=str,
    required=True,
    help="Path to the Master HDF5 file that contains the simulation results."
)
parser.add_argument(
    "--out-dir",
    type=str,
    required=True,
    help="Directory where the .npz file will be written."
)
args = parser.parse_args()

with h5py.File(args.master_file, "r") as master_h5:
    exporter = RateVoltageExporter(
        master_h5,
        Path(args.out_dir),
        num_time_bins=args.num_time_bins,
        smoothing_win=args.smoothing_window,
        out_name=args.output_name,
    )
    exporter.run()
