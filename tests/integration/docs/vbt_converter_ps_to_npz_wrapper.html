Direct parameter sweep to NPZ format conversion – Overview

Purpose

Run the convert_direc_to_npz.py converter, copy the resulting .npz and intermediate .h5 files to user‑specified locations, compare them against ground‑truth artefacts, and generate an HTML report for Allure.

Required environment variables

  • VBT_JOB_LOGS – directory where the script writes its log file.
  • CI_PROJECT_DIR – root of the repository (used to locate converters, ground‑truth data, etc.).
  • OUTPUT_HDF5_PATH – absolute path where the generated .h5 should be copied.
  • OUTPUT_NPZ_PATH – absolute path where the generated .npz should be copied.
  • INPUT_SWEEP_DIR_PATH – (optional) destination for the raw sweep directory that is attached to the CI job.

Command‑line interface

  • --input-dir <Path> (default: input) – folder that contains the raw sweep data.
  • --output-dir <Path> (default: output) – folder where the HTML report and link files are written.

High‑level workflow

  1. Initialise logging (file + stderr).
  2. Resolve CI_PROJECT_DIR → ci_root.
  3. Locate the converter script converters/convert_direc_to_npz.py.
  4. Create a temporary directory and build the expected output paths:
    • …/parametersweep_…/.npz
    • …/parametersweep_…/.h5
  5. Run the converter with arguments: 
    python convert_direc_to_npz.py --input_dir <input‑sweep> --output_file <npz> --intermediate_hdf5 <h5> --bin_size 0.1
  6. Copy the produced artefacts to OUTPUT_NPZ_PATH and OUTPUT_HDF5_PATH.
  7. Compare:
    • HDF5 → h5diff against tests/test_data/ground_truth/test_convert_output.h5
    • NPZ → custom compare_npz against …/test_convert_output.npz
  8. Render hdf5_npz_comparison_template.html → {output‑dir}/test_result_report.html.
  9. Generate small “download‑links” HTML files with create_link_html.
  10. Move the original sweep directory to INPUT_SWEEP_DIR_PATH (fast rename or safe shutil.move).

Produced artefacts (relative to --output-dir)

  • test_result_report.html – comparison summary.
  • converted_hdf5_&_npz_links.html – links to the copied .h5 and .npz.
  • input_sweep_dir_link.html – link to the uploaded sweep directory.
