Parameter sweep to HDF5 conversion – Overview

Purpose

Execute the convert_direc_to_hdf.py converter, copy the generated .h5 file, compare it with the ground‑truth, and produce a tiny HTML report for Allure.

Required environment variables

  • VBT_JOB_LOGS – directory for the log file.
  • CI_PROJECT_DIR – path to the repository root.
  • OUTPUT_HDF5_PATH – absolute destination for the resulting .h5.
  • INPUT_SWEEP_DIR_PATH – (optional) location where the raw sweep directory should be attached to the CI job.

Command‑line interface

  • --input-dir <Path> (default: input) – folder containing the parameter‑sweep data.
  • --output-dir <Path> (default: output) – folder for the HTML report and link files.

High‑level workflow

  1. Set up logging (file + stderr).
  2. Resolve CI_PROJECT_DIR → ci_root.
  3. Locate converters/convert_direc_to_hdf.py.
  4. Create a temporary directory; expected output: 
    …/parametersweep_…/.hdf5
  5. Run the converter: 
    python convert_direc_to_hdf.py --input_dir <input‑sweep> --output_file <hdf5>
  6. Copy the produced file to OUTPUT_HDF5_PATH.
  7. Run h5diff -q against the ground‑truth file tests/test_data/ground_truth/test_convert_output.h5.
  8. Render hdf5_comparison_template.html → {output‑dir}/test_result_report.html.
  9. Generate a link HTML file (converted_hdf5_link.html) using create_link_html.
  10. Move the original sweep directory to INPUT_SWEEP_DIR_PATH (rename or shutil.move).
  11. Create input_sweep_dir_link.html for the attached directory.

Produced artefacts (in --output-dir)

  • test_result_report.html – result of the h5diff comparison.
  • converted_hdf5_link.html – download link for the copied .h5.
  • input_sweep_dir_link.html – link to the uploaded sweep folder.
